# Home Automation

> **Status:** Automation utility

A practical home-automation project connecting device control, scheduling, and cloud execution into a simple utility workflow.

## What This Repo Shows

- Built around a practical workflow or operational problem instead of a purely visual demo.
- Keeps scope focused and useful rather than overengineering the implementation.
- Demonstrates pragmatic product decisions and a bias toward shipping helpful utilities.

## Tech

Node.js, TypeScript, Google Cloud Functions, Tuya API

## Run Locally

```bash
npm install
npm run dev
```

## Notes

This repo reflects my preference for practical, useful tools over demo-only builds.
